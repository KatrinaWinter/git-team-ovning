# git-team-ovning

## Om projektet

Det här är ett övningsprojekt för att träna på Git och
samarbete i team.

## Mål

- Arbeta med feature-branches
- Skapa commits
- Använda Pull Requests
- Samarbeta via GitHub med tydlig kommunikation och regelbundna avstämningar

## Arbetsflöde i team

1. Skapa en feature-branch.
2. Gör ändringar och skapa commits.
3. Pusha branchen till GitHub.
4. Öppna en Pull Request.
5. Granska och merga ändringarna.
